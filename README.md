
# Campus Notifications Microservice

A simple campus notification platform built using Node.js, Express, React, and Material UI.

The application fetches notifications from the provided protected API, prioritizes important notifications, and displays them in a clean frontend interface.




https://github.com/user-attachments/assets/f8d9ffd5-67b0-43f5-8a6a-c4200efba912








## Features

- Fetch notifications from protected API
- Priority-based notification sorting
- Logging middleware
- React frontend with Material UI
- Separate pages for all and priority notifications
- Responsive UI
- Backend and frontend integration

## Tech Stack

### Backend
- Node.js
- Express.js
- Axios

### Frontend
- React
- Vite
- Material UI
- React Router

## Run Backend

```bash
npm install
npm run dev
````

Backend runs on:

```txt
http://localhost:5000
```

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```txt
http://localhost:3000
```

## Notes

* Notifications are fetched from the provided AffordMed API.
* Environment variables are used to securely store access tokens.
* A screen recording demonstrating the application is included with the submission.
